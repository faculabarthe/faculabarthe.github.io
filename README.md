# Portfolio de Facundo Labarthe

Portfolio estático en HTML, CSS y JavaScript, con estética dark/terminal.

## Archivos

- `index.html` — estructura y contenido.
- `styles.css` — diseño responsive, estética terminal y animaciones.
- `script.js` — menú móvil, scroll, galería de imágenes y formulario de contacto.
- `assets/facundo.jpg` — foto de perfil.
- `assets/lugares-*.png` — capturas del proyecto Lugares Full Stack.
- `assets/CV-Facundo-Labarthe.pdf` — CV descargable.

## Cómo probarlo

Abrí `index.html` en el navegador.

## Para subirlo

Podés subir esta carpeta a GitHub Pages o conectar el repositorio con Vercel.

## Importante

Los proyectos `gestion-gastos-pagos` y `gestion-bicicletas` no muestran capturas inventadas: usan bloques visuales de código hasta que tengas imágenes reales.
